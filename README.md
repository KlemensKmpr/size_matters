# Size Matters!
Size Matters! ist ein Größenratespiel. Du siehst ein Referenzobjekt und versuchst, das Zielobjekt mit den Buttons „Less“ und „More“ auf die richtige Größe zu bringen. Wenn dein Tipp höchstens 15 % von der tatsächlichen Größe abweicht, gilt er als richtig.
Im Chat kannst du der KI Fragen stellen. Sie gibt dir Hinweise, ohne die genaue Größe zu verraten. Auf der Statistikseite siehst du deine gespielten Runden und wie gut du abgeschnitten hast.
Der API-Key wird in der Seitenleiste eingegeben und steht nicht im Code.
